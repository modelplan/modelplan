# Licensing map

This repository contains different kinds of material. A single badge does not relicense everything.

- **Software:** MIT (`LICENSE`, and `codex/LICENSE`), including the public computation core, CLI, plugin/desktop functional code and neutral community UI. Dependencies retain their own notices.
- **Open data:** per-file SPDX licenses in `data/manifest.json`; see `data/LICENSE`. Model Plan's new original-data publication uses CC BY-SA 4.0; previous CC BY 4.0 grants remain valid and third-party material keeps its terms. The transition does not create copyright over unprotectable facts.
- **Historical public visuals:** versions already released under MIT retain that grant. Their use does not imply official affiliation.
- **Official visual additions:** new reserved graphics/materials/3D/animation implementation lives in a separate private package, outside this repository. Official binaries assembled with it are mixed-license; their visual permission does not replace the software licenses.
- **Brand identity:** see `TRADEMARKS.md`. Brand rules do not withdraw code/asset copyright grants or restrict truthful lawful references.

Changing the current release's license policy does not recall previously distributed copies. Preserve the relevant historical and contributor notices. Add a scoped license before publishing a new material type; consult the owner when the scope is unclear.
