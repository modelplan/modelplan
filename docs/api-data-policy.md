# API service versus open data

The read-only API is publicly reachable; that does not make all responses an MIT or CC-licensed dataset. The canonical API Data Terms are published at https://modelplan.ai/api-terms.md. Ordinary queries, personal/commercial clients, Agents, attributed result display, reasonable application caching and calendar subscriptions are permitted. Bulk extraction for redistribution, data resale and replacement APIs require separate authorization to the extent of rights ModelPlan controls.

The explicit `data/manifest.json` files keep their own licenses. CC-licensed copies remain commercially reusable and redistributable under their licenses, even if the same facts appear in an API. Existing CC BY 4.0 and MIT grants are not withdrawn. Upstream rights, public-domain facts and applicable legal exceptions are separate; no right is created by simply attaching an API policy.

New open exports are deliberately limited to integration aliases/directories, public schemas, vendor guidance/defaults and separately licensed upstream open material. Maintained production plan/evidence/rule records and full calibration are not new blanket open exports. The one-way mirror removes withdrawn files from its current tree after the updated producer export is deployed; historical copies remain under their prior grants. Do not manually edit mirrored facts here.

Public access is not an unlimited-volume promise. Document only technical limits that are actually deployed; client code and CORS are not protections against copying. No account system is introduced by this source/license migration.
