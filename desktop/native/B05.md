# B05 native primitive calibration

Generic MIT functionality with deliberately neutral synthetic artwork. This does not implement the official dock/cockpit or accept any appearance before B00. No personal readers or CLI processes run in the probe.

`EffectResourcePool` admits at most 4,000,000 host-decoded image bytes, including leased atlases retained by live layers. Its nine-pose alpha masks are shared across subscription identities and tints. Pinned entries cannot be evicted to make a memory counter look smaller; admission fails to a static vector fallback. Stop an effect before releasing it or invalidating resources. The pool exposes counted/peak bytes and refusals. The application composition root should own one pool and inject it into all its SteppedEffect consumers; the standalone calibration window owns one pool for all six identities. Core Animation's discrete keyframes implement a one-second nine-step cycle without a redraw timer. Discrete keyTimes contain values.count + 1 boundaries, starting at zero and ending at one, as Apple documents; the live-cadence check observes actual presentation-image transitions. Host CPU does not account for WindowServer/GPU/energy cost.

`CautionState` uses stable semantic episode IDs and monotonic elapsed time. Unchanged snapshots do not restart its ten-second deadline; worsening/recurrence do. Timeout remains unacknowledged. `CautionControl` sets the steady model opacity and adds one finite CA animation; common-mode deadline delivery, press, hide/show and reduced-motion paths are checked. Its visible legend is always ALERT; accessibility labels/state are bilingual. A cursor's finite animation is removed explicitly when typing completes. The probe's lamp workload generates new synthetic episodes every 10.2 seconds so a sixty-second sampling interval contains repeated bounded episodes; this fixture timer is not a product redraw/blink loop.

`RenderProfile` keys appearance, scale, locale/font policy, colour space, viewport and accessibility flags. `AppearanceResolver` coalesces per-view transactions and uses the workspace notification center for accessibility display changes. Its consumer must call invalidate when changing preference overrides. The calibration row retains native control objects/IDs across reconfiguration, exposes a local-only adjustable effort with separate current/trial/recommended meanings, native help and a chart data alternative. No trial mutates an Agent.

Dock dwell, grace, hit-zone and slack live in DockTiming. These calibration/reference defaults are provisional pending the later owner brief; no new production timing choice is implied.

## Reproduce

Use the reviewed full Xcode via process-local DEVELOPER_DIR and macOS 14 deployment targets:

```sh
swift run --package-path desktop/native ModelPlanPrimitiveChecks
swift run --package-path desktop/native ModelPlanPrimitiveChecks --native-menu
swift run --package-path desktop/native ModelPlanPrimitiveChecks --live-cadence --output /tmp/cadence.json
bash desktop/native/tools/package-probe.sh /new/output-directory
python3 desktop/native/tools/measure-primitives.py /new/output-directory/ModelPlanPrimitiveProbe.app /new/measurement-directory
```

The executable is universal and ad-hoc Hardened Runtime signed for local testing, not a distribution build. Apple silicon is tested; Intel remains untested (3D may stutter), as in the owner deployment decision. It does not request TCC permissions. Close a run or cover its window and the measurement is rejected. The sampler retains actual PID/birth/cumulative time/footprint readings and the signed executable hash. Three 30-second warm + 60-second/1Hz rounds cover baseline, one/two/six distinct working IDs, steady/blinking lamp and typing cursor. Compare matched baseline/steady and active-state CPU; report raw units and sampling limits. Never claim a retained-helper or GPU cost is zero because host CPU is low.

The probe accepts `--mode`, `--seconds` (at most 180), `--receipt`, `--captures` and `--follow-system yes`. Capture mode exports only its own synthetic layer tree as sRGB JPEGs for English/Chinese, day/night and 1x/2x output. These are model-layer render receipts, not proof of a physical 1x display or final web/native pixel parity. Physical keyboard/VoiceOver/focus/display checks require separate real input. No permission, login item, merge or release action is included.
