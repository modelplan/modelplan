# Dock state before visual freeze

The `Logic/` directory contains only generic, MIT presentation logic. It imports Foundation/CoreGraphics, not AppKit, WebKit or a drawing/runtime scene. There are no windows, timers, gestures, CLI calls, rankings, personal-history storage, colours, fonts, artwork or production UI in it. `WindowInputProof/` remains a separate synthetic B05b harness; it is not the dock appearance.

## Interface and invariants

- **`DockSubscriptionPreferences`** stores only ordered stable subscription IDs and hidden IDs. The catalogue must contain unique nonempty IDs. New IDs append in source order, absent preferred IDs are kept for reconnect, and visibility does not erase order. Resetting order does not reset visibility. A drag session previews from its captured baseline, so repeated hover is idempotent. Only commit mutates order; cancel, a changed catalogue/order, or a repeated commit fails without reviving removed IDs. Drop uses the target's original index; keyboard up/down uses the same `move` interface. The caller owns bounded preference-file persistence.
- **`DockVisibilityState.step`** consumes a current presence snapshot, explicit intent and finite nondecreasing elapsed time. It returns surface state, one-time reveal/collapse effects, stale locks to clear, a generation token and at most one absolute deadline. It creates no timer. The adapter uses the app's sleep-aware elapsed clock, schedules in appropriate run-loop modes, passes `expectedGeneration` and samples current native truth again at a deadline. Normal app deactivation is not lifecycle cancellation. Lock/sleep/display removal uses `lifecycleCancel`; old callbacks cannot restore a surface by replaying an old action. Fullscreen/edge eligibility is supplied by the native owner, never guessed from pointer position.
- All hide/dwell/guard/slack constants live in **`DockVisibilityPolicy`**. Defaults: 150 ms reveal, 500 ms leave, 2 s stale lock recovery, 300 ms arrival guard, 150 ms sampling, 12 pt retention slack, 16 pt wake zone. An actual mouse button, menu, ignition hold or pinned card protects indefinitely; stale recorded drag/menu/keyboard flags alone do not. The whole wake target counts as inside. Unknown pointer state does not count as absence. A keyboard/AX explicit entry bypasses the arrival-pointer guard.
- **`DockPresenceArea`** computes hover retention, including full-depth card corridors, from supplied geometry. It does not choose artwork or control sizes. Its padded rectangles **must not become native input windows or click regions**: the real original-event route is the separate B05b gate.
- **`DockAttentionState.project`** reconciles current typed signals automatically, emits per-subscription semantic segments/dots and a single highest-priority menu notice. The sliver base remains neutral. Geometry supplies subscription-to-station mapping; overflow can share a station without losing account identity. No rank collapses the whole sliver to one colour.
- Notice priority is forecast, announced reset (hollow blue), confirmed reset (solid blue), expiring card (amber), then observed credits (white). Low quota alone is not a notice. Forecast/credits/card signals require fresh personal data. A dated public reset does not imply a personal meter refill. Expiry is an explicit UTC date, not an invented nominal period. Forecasts are upstream validated signals, not locally recomputed recommendations. Card IDs are sorted before key construction; every key includes subscription identity.
- Call **`acknowledgeDockOpen` only on a genuine dock opening**, not every data repaint. It acknowledges the selected notice and current fresh severity. Improved fresh severity lowers the baseline; unknown/stale evidence does not pretend that an alert improved. `acknowledgeCockpitOpen` acknowledges the menu notice only. Acknowledging the sliver never clears the open-dock event. `firstAppearance` is consumed explicitly only when a notice is actually presented, separately per surface. Temporary staleness withholds personal notices but preserves acknowledgements until the original deadline; expired/removed keys are pruned. Only the selected event is acknowledged; a hidden lower-priority event remains discoverable.

## Data integration stays explicit

The adapter must start from the shared store's validated, deadline-retired projection and stable subscription bindings; it must not re-read the CLI or bypass Core's expiry/clock rollback ledger. Do not group subscriptions by vendor, attribute source-wide events/speed to an account, or infer quota consumption from tokens. `DockSubscriptionSignal` is an input contract, not a parallel snapshot decoder. Missing scoped data stays unavailable; the adapter must retain known catalogue IDs across a transient read failure rather than treating that failure as deleting all subscriptions.

The current shared `AdviceEvent` DTO does not expose a subscription reference. Whether a newer CLI payload supports it has not been established by this preparation task. A multi-subscription adapter therefore needs the Core owner's reviewed binding seam; do not guess it from source/window strings. Shared Package.swift/Core/Shell/CI are intentionally unchanged. The coordinator can add a target with path `ModelPlanDock/Logic` and a check target with `LogicChecks`; the standalone proof is not library source.

## B06 native instrument foundation (visual acceptance still pending)

`DockInstrumentModel` separates fixed shorter/longer quota arcs from the selected readout and its actual-duration reset fraction. Period-order hints are never used as observed durations. Time-point positions are supplied by the frozen appearance recipe and lit with `ceil(time × positions)`; unknown time omits the clock. Work identity uses a fresh verified subscription match and a separately reported working/output fact, never an aggregate throughput or a minimum-sample rate guess.

`Native/` contains a generic static CoreGraphics/CoreText renderer and a constrained external resource reader. Neither includes official images, fonts, distinctive silhouette/geometry constants or palette data. Images are hashed and header-checked before decode; local paths cannot escape the supplied root. The counted LRU stores at most its configured decoded-byte budget. Font data must be genuine SFNT, and CoreText starts from the font's default CGFont rather than accidentally picking the first Thin named instance.

`InstrumentProof/main.swift` is a separate synthetic executable entry. Argument 1 is an owned output directory; optional argument 2 points to external converted test fonts. Without argument 2 it needs no private assets. It exercises cache accounting/refusal, path/hash rejection, native raster dimensions and CoreText text. It opens no window and does not establish official pixels, effects or physical input acceptance. Shared target/CI registration belongs to the integration lane.

The static renderer explicitly reports `effectsRendered=false`. Official repeating jets must use the shared counted provider/consumer seam; the static renderer does not substitute a triangle, bake a fake moving jet into a bitmap or keep a second decoded-frame cache. No B07/B08/Settings/entrance work is included.


`DockInstrumentView` exposes local subscription/notice/overflow intents and stable accessibility children; it never calls an agent or mutates an account. Failed resource transactions remove old actionable nodes. Its alpha hit test consumes parent-view coordinates and explicitly normalised RGBA pixels. This local test is **not** cross-application original-click forwarding. Window/display/backing/appearance and workspace accessibility-display changes retire effects before asking the host for a fresh, fully resolved presentation. The host remains responsible for Core expiry, actual profile resolution, lifecycle/display routing and later dock behaviour.

`DockWorkingEffects` receives the composition root's single `EffectResourcePool`. It admits only distinct verified working IDs and uses `SteppedImageEffect` with an injected immutable provider; no decoded jet is stored in `DockArtworkStore`. Failed admission leaves the jet unavailable. Hide/dispose/profile replacement stops and releases old consumers; unleased cache retention is bounded by the shared pool. Optional screen compositing uses the public macOS Core Image filter interface. Static 3x sampling is available for offscreen reference checks, while the actual view accepts only native 1x/2x profiles.

The native checks now also exercise self-contained static SVG, rejection of external resource references, stable/removed AX objects, asymmetric painted/transparent alpha coordinates, six consumers sharing three variants within 4,000,000 bytes, capture seeking, Reduce Motion and disposal. The SVG path still needs the minimum-runtime check; a successful current-host render is not macOS 14 acceptance. Public CI uses neutral generated resources only. Official visual recipes, original assets, exports and visual/resource receipts remain external/private, and passing this synthetic executable never claims their pixel/contrast/CPU/input acceptance.

The explicit `restoreFromCockpit` intent resolves the final suppressed/sliver/expanded state before the host inserts its view. Auto-hide plus an away/unknown pointer restores directly to sliver, while a verified painted/slack/wake hit or auto-hide off permits expansion. The host still supplies actual native pointer truth and owns close routes; no new timer/controller is created. Readout visibility is separately injectable, so percentage-off hides only its painted text while preserving the semantic AX value.

SVG dimension admission and decoding use the same bounded normalise-then-multiply calculation. Nonfinite, nonpositive, subnormal or oversized source dimensions and unbounded pixel requests are rejected before integer conversion or AppKit drawing. The instrumentation-only SPI exposes both parser/decoder and sizing to the standalone neutral checker; it is not a supported product API. Tiny normal dimensions and extreme aspect ratios either produce bounded output or a typed unsupported-representation error. Exact 4096 boundaries are exercised without allocating an oversized square.

Self-contained vectors may omit both dimensions and use a finite, bounded `viewBox` as their intrinsic size, including negative origins. Partial/malformed dimensions, invalid viewports and out-of-range origins fail closed. The original SVG bytes remain hash-checked and go directly through AppKit; the decoder neither rewrites the mark nor applies a vendor tint. Neutral checks cover 20/40-pixel intrinsic-white rendering, counted reuse/purge and invalid viewBox inputs. This current-host check does not certify the minimum macOS runtime.

The dock effect adapter accepts an optional `DockEffectRotation` recipe. Its linear CA transform applies only to each eligible effect image; the shared nine-pose discrete contents animation stays on its original one-second clock. No rotation is enabled by default and official periods remain external. App-profile or system Reduce Motion stops both timelines; the system signal defaults to NSWorkspace and is injectable for neutral checks. Quiet IDs retain frame zero from the same counted atlas. Capture holds both timelines and cannot advance a quiet/reduced bitmap. Reset, hide, detachment and disposal retire the effect's animations and leases. The host uses this same seam for main and overflow station surfaces; this is not a B07 window/controller release.

## B07 edge/sliver behavior

`DockEdgeGeometry` consumes session-resolved display frames/visible frames (and an optional additional safe frame) plus already-scaled registered layouts. It never persists display IDs, uses `NSScreen.main` as preference identity, invents a floating placement or emits top. Its injected `alongAnchor` preserves registration when full painted bounds are asymmetric about the sliver centre. It subtracts adjoining-display intervals using physical topology, fits the whole footprint between physical corner clearances, avoids a visible system-Dock edge when alternatives exist and normalizes missing/top/drop placement to an exposed allowed edge. All other displays remain in topology during fallback. Exact shared endpoints cannot wake. If no registered footprint fits, it returns no placement; there is no automatic nozzle/font shrinking.

`DockEdgeController` reuses `DockVisibilityState` and `DockPresenceArea`. Inject a cheap current environment, a sleep-aware elapsed clock and a dedicated scheduler; the convenience initializer uses the existing Core continuous-time source. Prepare layout/paint geometry on actual data/profile/display changes, not on every pointer sample. Active sliver/expanded tracking uses one one-shot common-mode timer and does not redraw unchanged presentations. Suppressed surfaces wait for host environment events. Deadlines always resample truth; cancelled generations cannot revive a surface. Menu/mouse/ignition/pin protection comes from actual host truth, separately from recorded drag/menu/keyboard locks.

Only `presentation.paintedFrame` is a window/input frame. The physical wake rectangle,12pt slack and full-depth card corridor are **not** invisible input windows. A sliver view paints an injected bounded image (neutral fallback available) and exposes an AX reveal action; its retained raster/mask bytes are reported. The host supplies registered sliver thickness/length for each profile so appearance can scale while wake remains physical. The existing view's `isPainted(atLocal:)` is available to the B05b window-routing owner; returning nil from NSView hitTest alone is not proof of original cross-application event passthrough.

`DockBackgroundDragRegions` receives the actual body/grip paths and control exclusions. Ignition/nozzles must be excluded by the appearance owner. The adapter offers grab/grabbing cursors and a click-through snap-outline view; the window owner must also make the outline panel ignore input. Drag preview never floats the committed dock; same-edge moves preserve the grabbed-point offset, and drop commits a nearest-edge intent once. Escape, lifecycle/display changes and removal cancel it. A native release event completes before stale-lock fallback; a missing release still recovers from fresh unprotected truth. Rebind drag regions when the registered layout changes; old regions are disabled on the new edge. No subscription reorder is implemented here (B08 owns it).

The action gate distinguishes pointer and AX sources, so a genuine reveal's arrival guard cannot be bypassed by pointer actions and does not block deliberate AX entry. A synchronous snapshot refresh at the gate re-hit-tests the original physical pointer target and rechecks stable AX nodes before dispatch. No key window or first responder is requested by reveal. Cockpit-close restoration resolves sliver/expanded state before publishing, avoiding an expanded-frame flash.

### Host seams (M0)

- Resolve durable display UUID/ambiguous/mirror fallback upstream; pass unique current session IDs and prepared layouts. On screen/usable-frame/backing/profile changes refresh them. Supply current pointer, card frame and actual protection facts. Resolve fullscreen, enabled/auto-hide and cockpit opening/open policy upstream; capture hiding remains unsupported. `DockNativeInputs` offers read-only current screen/pointer/button sampling, not preference persistence or a global input monitor.
- Atomically apply each presentation to owned windows/views, bind the matching body/control hit regions and route only painted pixels through the existing B05b original-input policy. A reveal callback is an event for the app's existing hint/notice policy, never a second hint queue. Root lifecycle/Space/display transitions must stop/resume/cancel the controller and the actual menu/ignition/card owner; window policy remains shared.
- Route captured drag/end/Escape to the adapter. Treat `onCommittedPlacement` as a local intent and map it to app-owned durable preferences; this module writes no Settings state. Feed current card/pin/menu truth from later consumers without converting retention rectangles into input surfaces.
- Forward environment changes with `refresh`/`setPreference`, genuine cockpit close with `restoreAfterCockpitClose` and lifecycle teardown with `stop`. Real source-data expiry/caution deadlines remain with Core/the app and must continue in tracking modes. This UI tracker runs no CLI or independent data freshness policy.

Geometry/state tests and synthetic common-mode/AX/event checks are not physical monitor, original input, fullscreen/Spaces, pixels or performance acceptance. Missing integrated/physical proof is parked to B25 under the coordinator rule; B08 remains a separate batch.

## Optional temporal interpolation candidate

`DockEffectSampling.interpolatedCandidate` is an explicit, default-off candidate. It borrows the existing nine images through the counted effect's seek interface and performs cyclic linear CA opacity interpolation with public addition compositing. It decodes no additional atlas and creates no app-driven frame timer. One injected host epoch aligns the interpolation and effect-only rotation; the rotation period remains supplied independently. Quiet/Reduce Motion stay static. Capture holds both timelines, and hide/reset/disposal clear borrowed image references before releasing the shared lease. The worst six-consumer recipe adds54 small CA layers, not54 decoded images.

This changes the reference's nine stepped contents updates per second to compositor interpolation, not to a thirty-frame raster atlas. Native compositing appearance, GPU/backing cost, paired incremental CPU and total memory must be measured before the official provider selects it. Source/offscreen checks do not constitute that enablement gate. The default `stepped` path and private visual resources remain unchanged.
