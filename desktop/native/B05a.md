# B05a: field and hosted Settings resource spike

This is a standalone resource probe, not a production field integration or an acceptance of official art. The community app does not enable enlargement. The optional live field must stay disabled until the plateau, minimum-runtime capture and lifecycle gates have been accepted.

Build ModelPlanFieldProbe with SwiftPM, using the lane's scratch directory. Package that executable in an ad-hoc signed app (macOS 14 minimum) to establish a separate LaunchServices responsibility identity. The app reads an explicitly supplied local resource directory containing index.html and the packaged field bridge; official field assets are supplied locally and are never included here. No CLI, account or real session data is loaded.

Run the tool through the lane's heavy slot:

    python3 desktop/native/tools/measure-field.py /path/to/ModelPlanFieldProbe.app /path/to/local/field-resources /path/to/new/receipts

The harness opens a minimal native window and SwiftUI Settings, then mounts/captures/releases ten field instances. It retains the first close for 180 seconds and later closes for 31 seconds, allowing 5/30-second post-close sampling. It records ready/settled errors and finite native release separately. The sampler retains process birth identity, physical footprint and cumulative Mach CPU counters. Helpers are attributed using the diagnostic responsibility_get_pid_responsible_for_pid symbol to the separately launched application's PID. This private diagnostic symbol is never called by the application. A missing symbol, non-self application responsibility, or missing helper proof must leave aggregate acceptance open. Retained helpers count; no helper is killed.

FieldSurface uses a scoped WKURLSchemeHandler and a nonpersistent store. Main-frame navigation is restricted to the packaged entry page. The page must include a CSP that blocks remote resources, downloads and connections; it must not receive personal data. Native configure uses structured JavaScript arguments. Messages are versioned and instance-bound. Ready/settled deadlines are 10/5 seconds; a visible WK snapshot has a 2-second deadline and must fit 2048x2048 pixels and 8 MiB encoded. Only one snapshot may be pending. Native disposal invalidates generation, cancels deadlines, removes handlers/delegates/views and releases without waiting for a disposed acknowledgement. One retained still remains bounded by the accepted snapshot limit.

The probe is deliberately narrower than B24. Full public-projection coalescing, keyed multi-profile persistence, production still display/HUD restoration and all F14 fault cases remain later integration work. The early resource receipt does not replace macOS 14 pixel/relaunch tests, genuine memory-pressure delivery, physical sleep/lock/display transitions, or full ten-cycle/inactivity acceptance of the integrated cockpit.

Measurement output is not an automatic pass. Evaluate 120,000,000-byte aggregate post-close plateaus, helper identity/retention, run interruptions and actual captured pixels. A successful binary build or a cleared native view alone is insufficient.
