The past-usage import now also reads Codex's archived threads (`archived_sessions`), so archiving a thread no longer hides its usage. A first-run import that could read no source stays owed, the engine starts an owed import at launch once a Claude Code or Codex history grant is recorded, and clearing a tool's history re-arms it (G3-112). `modelplan doctor readers` lists `codex:history` and `claude:history` with the import's coverage, reports a GLM key-file reader that has never read as `unavailable:not_read` instead of `stale`, and a signed-in Cursor account on the free or hobby plan as `no_plan` instead of `schema_changed` (G3-117). ZCode installed only as the CLI community package (`~/.local/share/zcode-community`, `~/.local/share/zcode-cli`) or the macOS support folder without a provider file now shows "This saved sign-in is not supported" instead of waiting for a first reading forever, also under a bare legacy GLM permission. The public `readerErrorCode` schema now lists `codex_custom_provider`, `team_unsupported` and `policy_pending`, which the CLI already emits.
