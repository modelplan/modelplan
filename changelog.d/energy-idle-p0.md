The engine does almost no work while nothing changes. The app-server keeps one in-memory list of the Claude Code, Codex and ZCode session logs it may read and lists a folder again only when it changed, instead of walking every history folder every few seconds; a new session still appears within 6 seconds, and an older session that resumes within 30 seconds. The 30-second observation pass skips a log whose size and time are as its last pass left them, and it no longer rebuilds the widget's data when it wrote nothing. `observed/observe-decisions.json` is now rewritten when an observer's outcome changes, not on every pass.
