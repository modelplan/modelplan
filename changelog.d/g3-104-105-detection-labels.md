Tool detection now uses only signals that belong to each tool. Settings no longer says Gemini CLI is installed on a Mac that only has Google Antigravity: Gemini CLI is detected from its command, its sign-in file or its chat history, not from the `~/.gemini` folder Antigravity also uses, and Antigravity is now detected as its own tool. Kiro is detected from the Kiro CLI it is read through, not from the Kiro IDE's folder. The OpenCode Go row says "OpenCode installed" instead of "detected", and says when no OpenCode Go key is set, because finding OpenCode does not mean there is an OpenCode Go subscription.
