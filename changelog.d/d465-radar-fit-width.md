The cockpit Resources column now sizes its radar by the column width instead of its height, so the radar fills the column, and its five rows (CPU, memory, disk, network, memory pressure) share the remaining height without cutting any name or value; side values drop first. In narrow English and Chinese columns (down to 91 pt) the pressure row keeps its value (Normal, Elevated, Critical) by shortening the name first, then showing the value alone; it is never cut.
