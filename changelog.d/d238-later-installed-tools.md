A supported tool installed after the first run is now noticed without restarting ModelPlan: the engine re-checks which tools are present (presence only, nothing read from them) when it starts, after wake and every 30 seconds, and a new tool that has not been allowed yet shows in the status menu as "Detected · Enable…", which opens Settings › Subscriptions. Nothing is read from it until you allow it there; Claude Code, Codex and ZCode, which are read by default, start reading on their own. The line goes away when you decide or uninstall the tool. ModelPlan remembers only which tool ids were present at first run (`detected-tools.json` in its data folder).
