The CLI now follows your proxy: `HTTP_PROXY`, `HTTPS_PROXY`, `ALL_PROXY` and `NO_PROXY` in either case, and on macOS the system proxy, so an app opened from Finder can reach the network through one. Automatic proxy files (PAC) are not supported yet, and `modelplan sync` and `doctor` now say so in plain words. A malformed proxy setting now fails with a clear reason instead of silently connecting directly. Saved sync errors are now fixed categories, so they can never hold a proxy address or password.
