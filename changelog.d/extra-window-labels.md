An extra quota window is now named by what it is instead of "Other" in the widget card and the cockpit column: the ZCode MCP allowance reads "MCP" and a Claude model-only weekly window reads "Opus" or "Sonnet", at most six characters, always shown in full. The third row's heading in the cockpit reads that name when every column agrees and "Extra" when they differ; "Other" remains only for a window the engine cannot name.
