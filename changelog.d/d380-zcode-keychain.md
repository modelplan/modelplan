GLM (ZCode QR-code sign-in): ModelPlan now recognises a ZCode 3.19+ sign-in whose store key is in the macOS Keychain and asks for its own Keychain permission (off by default) before opening anything in ZCode's sign-in folder. Settings explains the choice and asks you to choose Always Allow when macOS asks. Reading that Keychain-bound sign-in still needs the signed app's credential connection (U7), which is not in this build, so the row stays "Keychain confirmation needed" for now. ZCode 3.11–3.18 stores read again once the same choice is allowed, with no Keychain prompt. A denied GLM API-key permission is never bypassed by a saved pasted key. A store ModelPlan cannot read automatically now offers to paste a Zhipu / Z.ai API key instead of a bare "not supported", with a link to the region's key console.
