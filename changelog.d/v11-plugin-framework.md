Cockpit plugin columns (v1.1 framework): plugins take empty engine-table columns after your subscriptions (at most six columns a page), empty columns show a + menu to connect a detected subscription or add a plugin, up to two plugins can be pinned to the first page, and Settings has a Cockpit plugins section to turn plugins on or off, order and pin them, and set each plugin's own options. Plugins only run while the cockpit is open and their column is shown. Only a placeholder plugin ships with the framework.
