ModelPlan no longer runs any program inside another app's bundle (for example the Kiro, Kiro CLI or Codex app copies, or a CodexBar link into CodexBar.app), so macOS no longer lists ModelPlan under App Management for "updating or deleting other apps"; every tool it starts for a reading is stopped together with anything that tool started. Kiro without a standalone Kiro CLI now says to install it from kiro.dev/cli instead of "cannot parse the saved reading". ZCode readings no longer disappear while ZCode runs: the sign-in check follows only the files and fields that name the account, so ZCode rewriting its telemetry or other state keeps the last good reading.
