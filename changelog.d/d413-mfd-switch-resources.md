The cockpit's big screen keeps its four page keys the same width while a screen is open: the Overview key itself becomes a compact "‹ Overview │ icon + short name" switch for the Calendar and Resources screens (Cal, Sys), with hover, pressed and keyboard states, and Escape or the left half returns. Screens no longer have a title row or a Close key. The Resources screen is now a four-card grid for CPU, memory, disk and network. Each card shows the current value, the peak and average, a detail line and a thin history line that turns amber above 80 % and red above 90 %. The centre bottom key switches between the last 10 minutes and the last hour; the hour is kept in memory only, as one-minute folds that keep the 5-second peaks.
