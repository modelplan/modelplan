Sessions and projects (D470, data only): a session's project is now its git repository root with worktrees merged into it, else a workspace the tool names, else a bucket (independent Codex chat, home folder, no project), so the home folder name, chat slugs and worktree UUIDs no longer appear as projects. The cockpit data adds a Usage ranking of every session and project by total tokens (input, output and cache) for today, 7 and 30 days, with share of the window, estimated cost, project kind and the tool's own session title (local only, behind the project-labels switch). Codex Auto Review is folded into one background-review row and is never a model. Sessions recorded under the older project rule are re-attributed from their own log or tool database the next time it is read, and are ranked under no project until then. Removed worktrees keep their repository through a remembered mapping that holds only keyed references (no paths); it is not kept while project labels are off and `project-labels off` deletes it.
